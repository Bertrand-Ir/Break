# Break — card image prompts (for Gemini)

Generate one image per line below. Save each with the **exact filename** shown, put instrument images in `art/instruments/` and beat images in `art/beats/`, then run:

```
python scripts/import_art.py
```

Any image you haven't made yet simply shows the built-in illustration.

### Tips
- If one image doesn't match the others (too bright, wrong background), ask Gemini to "redo it in exactly the same style as the others: darker, charcoal-black background".
- Any size is fine. The import script crops and compresses everything, to about 40 KB per image.
